# Política de segurança

## Como reportar uma vulnerabilidade

**Não abra uma issue pública.**

Use o reporte privado do GitHub: aba **Security** do repositório → **Report a vulnerability** (GitHub Security Advisories). A conversa fica privada até a correção.

Inclua, se possível:

- o que foi encontrado e onde (arquivo, rota, configuração);
- como reproduzir;
- o impacto que você imagina.

## Escopo

Projeto pessoal, mantido por uma pessoa, sem prazo garantido de resposta. Reportes sobre vazamento de segredos no repositório ou no histórico têm prioridade máxima.

## Segredo vazado

Se você encontrar um token, senha ou chave neste repositório, reporte pelo canal acima. O segredo será revogado antes de qualquer outra ação.
